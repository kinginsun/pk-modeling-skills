一、模型与建模方法

同一份数据、同一个结构模型（一级吸收单房室），分别用两种主流群体 PK 工具独立估计， 以验证工作流可复现、跨引擎结果一致。

1.1 结构模型 — 一级吸收单房室（口服）

NONMEM ADVAN2 TRANS2；Monolix 内置库模型 lib:oral1_1cpt_kaVCl。两者数学上完全等价。
房室： 吸收室 (depot, CMT=1) → 中央室 (central, CMT=2)
血药浓度：
  C(t) = (F·D·ka) / (V·(ka−k)) · (e−k·t − e−ka·t)
消除速率： k = CL / V
典型达峰时间： tmax = ln(ka/k) / (ka−k) ≈ 1.97 h（NONMEM 典型值）
ka — 一级吸收速率常数 V — 表观分布容积 CL — 表观清除率 F 并入剂量（mg/kg 给药）

1.2 统计模型 — 随机效应与残差误差

个体间变异（IIV）用对数正态（指数）模型；残差误差用「比例 + 加性」组合模型。
NONMEM（含体重异速缩放协变量）：
  KAi = θKA · eη₁ᵢ
  CLi = θCL · (WT/70)0.75 · eη₂ᵢ
  Vi  = θV · (WT/70)1.00 · eη₃ᵢ
  η ~ N(0, Ω)，Ω = diag(ω²₁, ω²₂, ω²₃)
  Yij = IPRED·(1+ε₁) + ε₂，ε₁~N(0,σ²₁)，ε₂~N(0,σ²₂)

Monolix Base（无协变量，walkthrough 主运行）：
  Pi = Ppop · eηᵢ（logNormal，P ∈ {ka, V, Cl}）
  combined1: sd = a + b·f（a 加性 mg/L，b 比例，c=1 固定）
注意两处模型设定差异：① NONMEM 控制流固定了体重异速指数（0.75/1.0，参考 70 kg）， Monolix Base 不含协变量；② 误差模型参数化不同（NONMEM σ²₁ 为比例方差、σ²₂ 为加性方差； Monolix combined1 为 a + b·f 的标准差形式）。因此 IIV / 残差项只做定性对比。

1.4 数据准备与建模流程

  • 数据转换（prep_data.R）：Monolix 长表 → NONMEM 事件记录格式 （剂量行 EVID=1/CMT=1/MDV=1，观测行 EVID=0/CMT=2/MDV=0，缺失用 .）。 踩坑：read.csv 默认不把 "." 当缺失，需 na.strings=c("NA",".")。
  • 控制流编写：按 easy-nonmem skill 的 bundled 参考（ADVAN 目录 / $INPUT 规范） 确认一级吸收单房室 = ADVAN2 TRANS2，观测默认中央室。
  • 运行：execute run1.mod -directory=theo_run -threads=4； Monolix 侧用 x86shim 强制插件以 x86_64 编译（Apple Silicon）。
  • 诊断（gof_plots.R）：读取 $TABLE 输出 sdtab1 画 GOF； 踩坑：文件首行是 TABLE NO. 1 横幅，需 skip=1，剂量行 DV 为 NA 需剔除。
  • 验收标准：MINIMIZATION SUCCESSFUL、协方差步完成、ETABAR≈0、 收缩率 <20–30%、GOF 无系统性趋势。
